cc-review is a local code-review daemon and Claude Code plugin. It puts the uncommitted working tree in front of you as a PR-style diff, streams your inline comments back to Claude in realtime, and blocks further edits until you press Submit. Everything runs on 127.0.0.1 from one Go binary and persists to local SQLite.
